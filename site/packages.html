Packages

Using a package

eskiuc add writes the dependency into eskiu.toml, fetches it with git and records its commit in eskiu.lock, so later builds reuse it without touching the network. A dependency is a git URL with a rev (a tag, branch or commit) or a local path, from any repository; the index only helps people find packages.

eskiuc new myapp
cd myapp
eskiuc add compress --git https://github.com/eskiu-packages/compress --rev v0.1.1
eskiuc run

A package's modules are imported by the package name and the file name, as in import <gpu/model>;. Chapter 13 of the Book covers manifests, locks and eskiuc test.

gpu

v0.7.2github.com/eskiu-packages/gpu

GPU compute, rendering, 3D models and machine learning for Eskiu, over WebGPU.

One API runs on Metal (macOS, iOS), Vulkan (Linux, Android) and DirectX 12 (Windows) through wgpu-native, with shaders in WGSL. It draws glTF and OBJ models with physically based shading, runs Llama models from GGUF or safetensors files (Llama 2 7B Q4_0 at 45 tokens per second on an M4 Pro; llama.cpp does 58 on the same machine) and trains small networks (97% test accuracy on MNIST). It has what a 3D renderer needs: several render targets, cube maps, GPU mipmaps, shadow maps, image-based lighting, morph targets, KTX2 and HDR textures, and camera and video frames drawn from YUV. On iOS and Android it draws into a GpuView of a ui app, and the same programs build for the browser through emdawnwebgpu, with a WebGL2 backend where the browser has no WebGPU. Desktop windows take keyboard, mouse, touch and gamepads. What it does, with its benchmarks

Nothing to install: the first build downloads wgpu-native 29, and SDL3 for a desktop window (<gpu/window>). With Eskiu 0.15.1, ESKIU_SYSTEM_LIBS=SDL3 links the system's SDL3 instead.

Install

eskiuc add gpu --git https://github.com/eskiu-packages/gpu --rev v0.7.2
eskiuc build
Example from the README 
import <io>;
import <gpu>;

string twice = "@group(0) @binding(0) var<storage, read_write> v: array<f32>;\n"
    "@compute @workgroup_size(64)\n"
    "fn main(@builtin(global_invocation_id) id: vec3<u32>) { v[id.x] = v[id.x] * 2.0; }\n";

Result<int, string> run() {
    float[256] data;
    for (i in 0..256) data[i] = (float)i;
    Gpu gpu = gpu_open()?;
    defer gpu.release();
    GpuBuffer v = gpu.storage(&data, sizeof(data))?;
    defer v.release();
    GpuKernel k = gpu.kernel(twice, "main")?;
    defer k.release();
    k.bind(0, &v);
    k.dispatch(4, 1, 1)?;
    v.read(&data, sizeof(data))?;
    printf("%.1f\n", (double)data[255]);
    return Ok<int, string>(0);
}

Result<int, string> r = run();
if (!r.ok) printf("error: %s\n", r.error);

scene

v0.2.3github.com/eskiu-packages/scene

A scene graph and material renderer for Eskiu, on gpu.

Nodes, cameras, shapes and glTF scenes, drawn with Constant, Lambert, Phong, Blinn or PBR materials under ambient, directional, point and spot lights, transparency sorted back to front, HDR with tone mapping and bloom, skyboxes, image-based lighting and shadow maps, plus input, physics, animation, particles and headset rendering for Meta Quest and Apple Vision Pro. Checked against analytic values on Metal, Vulkan and DirectX 12.

The first build downloads wgpu-native through gpu.

Install

eskiuc add scene --git https://github.com/eskiu-packages/scene --rev v0.2.3
eskiuc build
Example from the README 
import <gpu>;
import <gpu/math>;
import <scene>;

Result<int, string> draw(*Gpu gpu, *GpuTexture target) {
    Scene scene = gpu.scene()?;
    defer scene.release();
    SceneGeometry ball = scene_sphere(1.0, 48, 24);
    int mesh = scene.add_geometry(&ball)?;
    ball.free();
    SceneMaterial m = scene_material(SCENE_PBR);
    m.diffuse = Vec4{0.9, 0.2, 0.1, 1.0};
    m.roughness = 0.4;
    scene.add_object(0, mesh, scene.add_material(m));
    scene.add_light(scene_directional(Vec3{-0.5, -1.0, -0.3}, Vec3{1.0, 1.0, 1.0}, 2.0));
    scene.add_light(scene_ambient(Vec3{0.4, 0.45, 0.5}, 0.3));
    int cam = scene.add_camera(0, scene_perspective(0.9, 0.1, 100.0));
    scene.node(cam).position = Vec3{0.0, 1.0, 4.0};
    scene.look_at(cam, Vec3{0.0, 0.0, 0.0}, Vec3{0.0, 1.0, 0.0});
    scene.set_camera(cam);
    scene.post.tone_mapping = SCENE_TONE_HABLE;
    return scene.render_to(target);   // or scene.render(frame.view, w, h, surface.format)
}

onnx

v0.2.3github.com/eskiu-packages/onnx

ONNX model inference for Eskiu, over ONNX Runtime.

A model exported from PyTorch, TensorFlow or scikit-learn runs on the CPU everywhere, and on CoreML, CUDA, DirectML or WebGPU when the ONNX Runtime build has them. Wrong input names, types or shapes come back as error messages. Its image resizers give the same bytes as Pillow and OpenCV, and <onnx/detect> decodes SSD boxes and runs NMS bit for bit as numpy, so a Python vision pipeline moves over with the same numbers.

Nothing to install: the first build downloads ONNX Runtime 1.31 (macOS arm64, Linux and Windows).

Install

eskiuc add onnx --git https://github.com/eskiu-packages/onnx --rev v0.2.3
eskiuc build
Example from the README 
import <io>;
import <onnx>;

Result<int, string> run() {
    OnnxSession s = onnx_session("model.onnx", null)?;
    defer s.release();
    float[4] x = {1.0, -2.0, 0.5, 3.0};
    int64[2] shape = {1, 4};
    OnnxTensor input = onnx_tensor_f32(&x[0], &shape[0], 2)?;
    defer input.release();
    OnnxTensor y = s.run1(&input)?;
    defer y.release();
    *float out = y.f32();
    for (i in 0..y.len()) printf("%f\n", (double)out[i]);
    return Ok<int, string>(0);
}

Result<int, string> r = run();
if (!r.ok) printf("error: %s\n", r.error);

tflite

v0.1.3github.com/eskiu-packages/tflite

TensorFlow Lite model inference for Eskiu.

A .tflite model converted from TensorFlow, Keras, JAX or PyTorch runs on the CPU with XNNPACK, and on the GPU through the Metal delegate (macOS) or the OpenCL/OpenGL delegate (Linux). Quantized inputs and outputs are converted for you.

compress

v0.1.1github.com/eskiu-packages/compress

zlib, gzip, raw DEFLATE and ZIP archives for Eskiu, written in Eskiu.

DEFLATE at levels 0 to 9, zlib and gzip in both directions, and ZIP archives with ZIP64. Every read is bounds checked and the output is capped by a size limit, so a small file cannot expand into all of memory.

Nothing to install: no zlib and no C code.

Install

eskiuc add compress --git https://github.com/eskiu-packages/compress --rev v0.1.1
Example from the README 
import <io>;
import <compress>;

Result<int, string> run(*uint8 data, uint64 n) {
    Bytes gz = gzip_compress(data, n, 9)?;
    defer gz.free();
    Bytes back = gzip_decompress(gz.data, (uint64)gz.len)?;
    defer back.free();
    printf("%llu -> %lld -> %lld bytes\n", n, gz.len, back.len);
    return Ok<int, string>(0);
}

yaml

v0.1.1github.com/eskiu-packages/yaml

YAML configuration files for Eskiu, read into the standard library's JSON tree.

One YAML document under the YAML 1.2 core schema (block and flow collections, every scalar style, comments) becomes a JsonValue, so settings are read with json_get paths. Errors say the line and column. Pure Eskiu.

Nothing to install.

Install

eskiuc add yaml --git https://github.com/eskiu-packages/yaml --rev v0.1.1
Example from the README 
import <io>;
import <json>;
import <yaml>;

int main() {
    YamlError err;
    *JsonValue cfg = yaml_load("service.yaml", &err);
    if (cfg == null) {
        printf("service.yaml:%d:%d: %s\n", err.line, err.col, err.message.cstr());
        return 1;
    }
    defer JsonValue_free(cfg);
    *JsonValue port = json_get(cfg, "server.port");
    *JsonValue model = json_get(cfg, "models[0].path");
    printf("port %d, model %s\n", port != null ? (int)port.num : 80,
           model != null ? model.str.cstr() : "none");
    return 0;
}

audio

v0.4.1github.com/eskiu-packages/audio

Sound for Eskiu: WAV and Ogg Vorbis files, a mixer and output through SDL3.

Reads WAV files in every common encoding (PCM, float, IMA and Microsoft ADPCM) as ffmpeg decodes them, and Ogg Vorbis on every platform with a decoder written in Eskiu, whole or streamed, honoring the loop points a file carries. It mixes any number of voices with volume, pan, pitch, loops and gapless intro-to-loop playlists, and sends the mix to the default output device. In a ui app on iOS and Android it plays through the system (RemoteIO, AAudio) and decodes MP3, AAC and FLAC with the system's codecs.

<audio/wav>, <audio/ogg> and <audio/mixer> are pure Eskiu; <audio/device> needs SDL3 (brew install sdl3 on macOS).

Install

eskiuc add audio --git https://github.com/eskiu-packages/audio --rev v0.4.1
eskiuc build -L/opt/homebrew/lib
Example from the README 
import <time>;
import <audio>;

Result<int, string> run() {
    Sound jump = wav_load("jump.wav")?;
    defer jump.free();
    AudioDevice out = audio_open(48000)?;
    defer out.close();
    Mixer mixer = mixer_new(out.rate);
    defer mixer.free();
    uint32 voice = mixer.play(&jump, AudioPlay{volume: 0.8, pan: -0.25});
    while (mixer.playing(voice)) {
        out.pump(&mixer, 50)?;      // keeps 50 ms of audio queued
        time_sleep_ms(10);
    }
    return Ok<int, string>(0);
}

font

v0.1.1github.com/eskiu-packages/font

TrueType fonts for Eskiu: glyph outlines, antialiased rendering, text layout and atlases.

Reads .ttf files, renders glyphs into antialiased coverage bitmaps, lays out lines of UTF-8 text with kerning, and packs a character set into one texture for text on the GPU.

Nothing to install.

Install

eskiuc add font --git https://github.com/eskiu-packages/font --rev v0.1.1
Example from the README 
import <font>;

Result<int, string> run(*uint8 rgba, int width, int height) {
    Font f = font_load("DejaVuSans.ttf")?;
    defer f.free();
    f.draw("Hola, Eskiu", 32.0, rgba, width, height, 10.0, 40.0, 0xFFFFFFFF);

    GlyphBitmap g = f.render(f.glyph('g'), 64.0)?;   // one glyph
    defer g.free();

    // g.left and g.top place it from the pen on the baseline.
    return Ok<int, string>(0);
}

jni

v0.1.1github.com/eskiu-packages/jni

Native methods for Android and the JVM, written in Eskiu.

A native method of a Java or Kotlin class is an Eskiu function with the JNI name, with no C glue: strings cross as real UTF-8, lookups come back as a Result, and the whole JNIEnv table is there underneath. It runs on Android and on the desktop JVMs of macOS, Linux and Windows.

Nothing to install: the VM hands the library its tables.

Install

eskiuc add jni --git https://github.com/eskiu-packages/jni --rev v0.1.1
eskiuc build --target aarch64-linux-android24 -o libhello.so
Example from the README 
import <string>;
import <jni>;

// package com.example.hello; class Greeter { static native String greet(String name); }
*void Java_com_example_hello_Greeter_greet(*void env, *void cls, *void name) {
    JniEnv e = jni_env(env);
    String who;
    defer String_free(&who);
    e.string(name, &who);
    String out;
    defer String_free(&out);
    String_appendf(&out, "Hello, %s, from Eskiu", who.data);
    return e.new_string(out.data);
}

quickjs

v0.1.1github.com/eskiu-packages/quickjs

JavaScript for Eskiu programs, over QuickJS.

Embeds QuickJS, the engine rquickjs 0.6.2 bundles with the same patches, for games and tools that keep their logic in JavaScript. ES modules with top-level await, values both ways (JSON and typed arrays included), Eskiu closures as JavaScript functions, errors as a Result with their file, line and column, and memory, stack and time limits.

Nothing to install: the first build downloads the prebuilt QuickJS library for macOS, Linux, Windows, iOS or Android. Eskiu 0.15 or newer.

Install

eskiuc add quickjs --git https://github.com/eskiu-packages/quickjs --rev v0.1.1
eskiuc build
Example from the README 
import <io>;
import <quickjs>;

struct Player { double x; }

Result<int, string> boot(*Player p) {
    *JsRuntime rt = js_runtime()?;
    defer rt.release();
    rt.set_fs_loader("scripts");          // "./a.js" from the importer, "lib/b.js" from scripts/
    JsContext ctx = rt.context()?;
    defer ctx.release();

    JsValue engine = ctx.object();
    engine.set_fn("setX", 1, JsValue(*JsContext c, *JsArgs a) {
        p.x = a.num(0);
        return c.undefined();
    });
    engine.set_fn("log", 1, JsValue(*JsContext c, *JsArgs a) {
        printf("%s\n", a.str(0));
        return c.undefined();
    });
    ctx.set_global("engine", engine);

    JsValue ns = ctx.eval_file("scripts/main.js")?;
    defer ns.free();
    JsValue booted = ctx.call_global_opt("onBoot", null, 0)?;
    booted.free();
    JsValue dt = ctx.num(1.0 / 60.0);
    for (frame in 0..600) {
        JsValue r = ctx.call_global("onUpdate", &dt, 1)?;
        r.free();
    }
    return Ok<int, string>(0);
}

location

v0.1.6github.com/eskiu-packages/ui-location

Where the device is, for apps on eskiu-packages/ui.

A component calls use_location and gets the latest position while it is mounted, measured by the platform's own service: CoreLocation on iOS, LocationManager on Android and the browser's geolocation on the web. The first use asks for permission, and the package brings the framework, the usage text and the Android permissions through its ui.toml.

An app made with eskiu-packages/ui (ui new).

Install

ui new myapp && cd myapp
eskiuc add location --git https://github.com/eskiu-packages/ui-location --rev v0.1.6
ui run ios
Example from the README 
import <location>;

void Here() {
    Location here = use_location(true);
    if (here.status == LocationReady) {
        String text;
        defer String_free(&text);
        String_format(&text, "%.5f, %.5f (± %.0f m)", here.latitude, here.longitude, here.accuracy);
        Text(text.data);
    } else if (here.status == LocationDenied) {
        Text("Allow the location in Settings");
    } else {
        ActivityIndicator(Style{}, true);
    }
}

ar

v0.2.3github.com/eskiu-packages/ar

Augmented reality for apps on eskiu-packages/ui: ARKit on iOS, ARCore on Android, WebXR on the web.

use_ar_session (<ar/ui>) gives each frame's camera pose, planes, anchors, hit tests, image targets, light and depth, and the camera image in the same layout as the camera's frames, so <gpu/yuv> draws the background and scene the content. ARCore runs with no OpenGL context, the projection is computed in Eskiu the same way on every platform, and in Chrome on Android a WebXR session gives the same data.

An app made with eskiu-packages/ui (ui new), on a phone with ARKit or ARCore.

Install

ui new myapp && cd myapp
eskiuc add ar --git https://github.com/eskiu-packages/ar --rev v0.2.3
ui run ios
Example from the README 
import <ar>;

bool tapped;          // set by a tap at (tap_x, tap_y) in the 390 x 844 view
float tap_x;
float tap_y;

void World() {
    use_ar_session(ArOptions{horizontal: true}, void(*ArFrame frame) {
        // Borrowed for this call. Draw frame.image with <gpu/yuv>, then the world with:
        ArMat4 view = frame.view();
        ArMat4 projection = frame.projection(390.0, 844.0, 0.05, 100.0);
        ArHit[1] hit;
        if (tapped && frame.hit_test(tap_x, tap_y, 390.0, 844.0, AR_HIT_PLANES, &hit[0], 1) > 0) {
            ar_anchor_add_hit(&hit[0]);
            tapped = false;
        }
    });
}

canvas

v0.1.4github.com/eskiu-packages/ui-canvas

A 2D canvas for Eskiu, in a ui app (the GPU on phones, Canvas 2D on the web) or offscreen.

Sprites and pixel art drawn every display frame in a CanvasView: atlas cells into rects with nearest or linear sampling, opacity, a tint, mirroring and a transform stack, batched into one draw call per image. WebGPU through gpu on iOS and Android, the browser's Canvas 2D on the web; PNG, JPEG and, on phones, WebP.

An app made with eskiu-packages/ui (ui new); the first build downloads wgpu-native.

void Game() {
