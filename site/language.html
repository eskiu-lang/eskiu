The language

C's model, with what C is missing.

Memory is yours and calls are C calls. On top of that, Eskiu adds the parts people reach for other languages to get, with cleanup and control flow compiled into your program.

Errors and cleanup

Errors are values, cleanup is defer

Result carries the error, ? passes it up, and defer runs on every way out of the function.

Result<int, string> serve(string arg) {
    int port = parse_port(arg)?;
    *uint8 buf = (*uint8)malloc(4096);
    defer free(buf);
    printf("serving on %d\n", port);
    return Ok<int, string>(0);
}
Types

Sum types and checked null

An enum can carry data and match must cover every case. A ?*T has to be checked before it is used.

enum Shape { Circle(float), Rect(float, float) }

float area(Shape s) {
    match s {
        Circle(r) -> { return 3.14159 * r * r; }
        Rect(w, h) -> { return w * h; }
    }
    return 0.0;
}
Concurrency

async and await, compiled

An async function becomes a state machine at compile time. The event loop is a library in the standard library, not a runtime underneath your program.

async int read_once(EventLoop* lp, int fd) {
    int n = await net_read_async(lp, fd, &buf[0], 64);
    return n;
}
C interop

Inside a C or C++ codebase

export makes a function callable from C, C++ or Rust and --emit-header writes its header. A module drops into an existing engine one file at a time.

export int checksum(*uint8 data, int n) {
    int sum = 0;
    for (i in 0..n) sum = sum * 31 + data[i];
    return sum;
}

$ eskiuc lib.esk --emit-header lib.h

The compiler is written in Eskiu too, and both compilers, C++ and Eskiu, are held to the same output on every program in the test suite. Read the Book

What to expect

A young language, with explicit choices.

Eskiu is in the 0.16 series. Memory is managed manually; defer helps release resources, and bounds, overflow and null checks are enabled with --safe. There is no borrow checker.

Minor releases can change the language and standard library. Read the stability policy, release notes and requirements for each target before choosing it for a project.
