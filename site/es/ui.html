Crea apps nativas para Android, iOS y la web

Un componente es una función normal de Eskiu. Llama a Column, Text y Button para armar la vista y guarda su estado en signals. La app se compila a código máquina en iOS y Android, y a WebAssembly en la web.

Los textos, botones, campos, switches, listas, modales y alertas son los controles de cada plataforma, con su accesibilidad. 

import <string>;
import <ui>;

void Counter() {
    Column(Style{padding: 24, gap: 12}, void() {
        *Signal<int> count = use_signal<int>(0);
        String label;
        defer String_free(&label);
        String_format(&label, "Pressed %d times", count.get());
        TextWith(Style{font_size: 28, font_weight: 700}, label.data);
        Button("Press me", void() {
            count.set(count.get() + 1);
        });
    });
}

Escrito en Eskiu, dibujado por la plataforma

Los componentes, el estado y las reglas de layout son el mismo código de Eskiu en todas partes. En cada frame, el núcleo le manda a la plataforma un buffer con los cambios, y un host delgado los aplica a vistas reales acomodadas por Yoga, el motor que usa React Native.

iOSUIKit, desde Objective-C++
Androidandroid.view, desde Java y JNI
WebEl DOM, desde WebAssembly
macOSEl host web en una ventana de WKWebView

Actualizaciones que tocan solo lo que cambió

Cada bloque registra los signals que lee. Cuando uno cambia, solo ese bloque se vuelve a ejecutar y sus hijos se emparejan por llave, así una lista conserva el estado de cada fila cuando se reordena. Las listas virtuales montan solo las filas cerca de la pantalla, así que un millón de filas cuesta lo mismo que una pantalla llena.

Los hooks, las llaves y los memos se revisan mientras la app corre, y un error se detiene diciendo dónde ocurrió: in Column[0] > TodoRow[key 3].

8.1 mspara montar 10,000 filas
5.9 mspara invertir las 10,000
1.2 mscuando cambia un signal que leen todas las filas
0asignaciones pendientes tras 10,000 montajes y desmontajes

Pantallas en el teléfono, páginas en la web

Un router guarda una pila de rutas y un navigator la dibuja. En iOS y Android cada ruta es una pantalla que entra deslizándose, con el botón de atrás y el gesto desde el borde. En la web cada ruta es una URL, y los botones de atrás y adelante del navegador mueven la app. Los deep links abren su pantalla en las tres plataformas.

Las pantallas de abajo siguen montadas, así que al regresar están como las dejaste.

Navigator(router, void(string route) {
    List<String> params;
    defer route_params_free(&params);
    if (route_match("/places/:id", route, &params)) {
        PlacePage(router, atoi(params.data[0].data));
    } else {
        PlaceList(router);
    }
});

// en otra parte
router.push("/places/2");
router.back();

Código nativo cuando lo necesites

Una app o un paquete trae código por plataforma en native/: Objective-C o Swift en iOS, Java, Kotlin o C en Android, JavaScript en la web. Eskiu lo llama con funciones extern, el código nativo responde con eventos y puede registrar sus propias vistas para NativeView.

Las bibliotecas de terceros se declaran en ui.toml: las dependencias de Maven se compilan con Gradle y los paquetes de Swift con Xcode, y un paquete lleva las suyas a cada app que lo usa. 

# ui.toml
[app]
name = "Explore"
scheme = "places"

[ios.spm]
Collections = { url = "https://github.com/apple/swift-collections", from = "1.1.0" }

[android]
dependencies = ["com.google.android.material:material:1.12.0"]
permissions = ["android.permission.CAMERA"]

De cero a una app corriendo

La herramienta ui crea un proyecto y lo compila o lo corre en cada plataforma. Necesita emscripten para la web, Xcode para iOS y el SDK de Android para Android.

<ui/kit> agrega tarjetas, badges, botones, campos, checkboxes, pestañas, barras y acordeones con tema, hechos con los mismos elementos. 

git clone https://github.com/eskiu-lang/ui
eskiuc ui/tools/ui/main.esk -o ~/.eskiu/bin/ui

ui new myapp && cd myapp
ui run web        # o macos, ios, android

ui está en preview. Hoy las vistas usan lambdas explícitas; los trailing blocks, planeados para Eskiu 0.13, permitirán escribir Column(Style{padding: 16}) { ... } para la misma llamada. Los hosts de Windows y Linux llegan después.
