Apps nativas, escritas en Eskiu

Un mismo código para iOS, Android, la web y el escritorio. Cada plataforma dibuja sus propios controles, así que la app se ve y se comporta como la gente espera ahí.

Nativa de verdad

Textos, botones, campos, listas y alertas son los controles de la propia plataforma, acomodados por Yoga, el motor que usa React Native.

  • VoiceOver, TalkBack y el tamaño de texto del sistema
  • Contraseñas, teclados y autollenado en formularios
  • Modo oscuro, áreas seguras, hápticos, compartir
  • Cámara, ubicación y notificaciones como paquetes

Rápida de hacer

Guardas un archivo y la app que corre cambia en un tercio de segundo, en la misma pantalla y con su estado.

  • Un kit con tema: formularios, selectores, menús, toasts
  • Navegación que en el teléfono son pantallas y en la web URLs
  • Errores que nombran el elemento y su línea de código
  • Código nativo en Swift, Kotlin o JavaScript cuando lo necesitas

Hecha para agentes y pruebas

Un agente de código puede construir una pantalla, verla y recorrerla sin que nadie intervenga.

  • ui agent: el árbol, capturas, toques y texto
  • ui test: un archivo .uitest para todas las plataformas
  • Un reloj que controla la prueba, así que nunca espera
  • Nada de esto en un build de release

Una pantalla es una función de Eskiu

Los componentes son funciones comunes que guardan su estado en signals. Cuando un signal cambia, solo corren otra vez los bloques que lo leen. La app compila a código máquina en teléfonos y escritorio y a WebAssembly en la web, sin un puente de JavaScript de por medio.

import <ui>;

void Counter() {
    Column(Style{padding: 24, gap: 12}) {
        *Signal<int> count = use_signal<int>(0);
        TextWith(Style{font_size: 28, font_weight: 700},
            textf("Pressed %d times", count.get()));
        Button("Press me") {
            count.set(count.get() + 1);
        }
    }
}

<ui/kit> trae tarjetas, botones, campos, casillas, pestañas, barras, un calendario, menús, popovers y toasts, con tema claro y oscuro, en español o inglés, y con sus roles y estados para lectores de pantalla.

De una carpeta vacía a las tiendas

La herramienta ui crea el proyecto, lo corre mientras trabajas y construye lo que publicas.

  1. ui new myappUn proyecto con una app, una prueba y un AGENTS.md para agentes de código.
  2. ui serve iosCorre la app y la reconstruye cada vez que guardas. También android, web, macos, linux y windows.
  3. ui releaseBuilds firmados para App Store y Google Play, el escritorio y la web. ui open ios trabaja desde Xcode.

Instala la herramienta:

git clone https://github.com/eskiu-packages/ui
eskiuc ui/tools/ui/main.esk -o ~/.eskiu/bin/ui

ui 0.7 requiere Eskiu 0.16.2 o más nuevo. El núcleo, el kit y los hosts de iOS, Android y la web van hacia la 1.0.
