Eskiu para agentes

Un agente con su propia computadora (una máquina Linux, un contenedor) puede instalar Eskiu, escribir programas y apps, correrlos, verlos y probarlos con los comandos de esta página. Cada respuesta tiene una forma pensada para que la lea un programa.

Instala

El compilador y la herramienta ui, en ~/.eskiu cuando no se puede escribir en /usr/local:

curl -fsSL https://eskiu-lang.org/install.sh | sh -s -- --with-ui
export PATH="$HOME/.eskiu/bin:$PATH"
eskiuc doctor

En Windows, $env:ESKIU_WITH_UI = 1; irm https://eskiu-lang.org/install.ps1 | iex. O empieza desde la imagen de contenedor, que ya trae eskiuc, ui, emscripten y Chrome: 

docker run --rm -it ghcr.io/eskiu-lang/agent

eskiuc doctor dice qué tiene la máquina para cada tipo de build y qué falta. Un build nativo necesita un compilador de C (clang o gcc); una app web necesita emscripten (emcc) y, para manejarla, Chrome o Chromium.

Escribe y corre código

eskiuc run hello.esk                       # compila y corre un archivo
eskiuc new tool && cd tool && eskiuc run     # un paquete
eskiuc test                                # cada tests/*.esk, pasa con exit 0
eskiuc main.esk -o app --diagnostics=json  # errores como líneas JSON en stderr

Con --diagnostics=json cada error o warning es un objeto JSON: su severidad, un id estable, el mensaje, el archivo y el rango, hints y notas. Los ids están en diagnostic-ids.txt.

Construye una app y mírala

ui agent maneja la app en ejecución: la compila, la abre en un Chrome sin ventana (en la web) o en una ventana, y responde cada operación. --json da un objeto por operación. 

ui new myapp && cd myapp
ui agent web --json tree
ui agent web --json "tap add" "type title Milk" "clock settle" state
ui agent web "screenshot shot.png"
ui agent web --stop

Las operaciones son tree, layout, screenshot FILE, tap ID, type ID TEXT, scroll ID DY, back, clock +MS, clock settle, state, logs y perf. Los elementos se nombran con Style.test_id. El tiempo solo avanza con clock, así que nada cambia entre dos operaciones. En una máquina Linux que corre como root, Chrome necesita UI_CHROME_ARGS=--no-sandbox.

Las mismas operaciones manejan la app en ventanas de macOS, Linux y Windows, en el simulador de iOS y en Android, cuando la máquina los tiene: ui agent ios ..., ui agent android ....

Pruébala

# tests/ui/counter.uitest
expect count text "Count: 0"
tap Increment
expect count text "Count: 1"
expect screenshot counted 0.5%

ui test web --json

Un archivo .uitest corre igual en cada plataforma. Cada app que crea ui new empieza con uno, y con un AGENTS.md que le dice a un agente cómo trabajar en ella.

Sin computadora propia

Un agente que solo conversa (Claude, ChatGPT y otros clientes MCP) llega a Eskiu por su servidor MCP, una URL remota sin clave: 

https://eskiu-mcp-9450.orvex.cloud/mcp

Busca en el compilador, la biblioteca estándar y la documentación, y corre código en un worker: eskiu_run compila y corre un archivo, eskiu_ui_render construye una app de ui para la web, aplica operaciones de ui agent y regresa una captura, y eskiu_ui_test corre un archivo .uitest contra ella.
