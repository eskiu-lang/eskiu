The language

C's model, with what C is missing.

Memory is yours and calls are C calls. On top of that, Eskiu adds the parts people reach for other languages to get, and none of them needs a runtime.

Errors and cleanup

Errors are values, cleanup is defer

Result carries the error, ? passes it up, and defer runs on every way out of the function.

Result<int, string> serve(string arg) {
    int port = parse_port(arg)?;
    *uint8 buf = (*uint8)malloc(4096);
    defer free(buf);
    printf("serving on %d\n", port);
    return Ok<int, string>(0);
}
Types

Sum types and checked null

An enum can carry data and match must cover every case. A ?*T has to be checked before it is used.

enum Shape { Circle(float), Rect(float, float) }

float area(Shape s) {
    match s {
        Circle(r) -> { return 3.14159 * r * r; }
        Rect(w, h) -> { return w * h; }
    }
    return 0.0;
}
Concurrency

async and await, compiled

An async function becomes a state machine at compile time. The event loop is a library in the standard library, not a runtime underneath your program.

async int read_once(EventLoop* lp, int fd) {
    int n = await net_read_async(lp, fd, &buf[0], 64);
    return n;
}
C interop

Inside a C or C++ codebase

export makes a function callable from C, C++ or Rust and --emit-header writes its header. A module drops into an existing engine one file at a time.

export int checksum(*uint8 data, int n) {
    int sum = 0;
    for (i in 0..n) sum = sum * 31 + data[i];
    return sum;
}

$ eskiuc lib.esk --emit-header lib.h

The compiler is written in Eskiu too, and both compilers, C++ and Eskiu, are held to the same output on every program in the test suite. Read the Book →

In production

ViroReact's engine, rewritten in Eskiu.

ReactVision is replacing the C++ engine under ViroReact with one written in Eskiu. It implements ViroReact 3.2's whole public API on iOS, Android, Meta Quest and Apple Vision Pro, and runs ReactVision's showcase app unchanged. It is in device testing before it replaces the native engine.

A note from the developer

A note from the developer

I learned to program with Ruby, but the more I built, the more I found C underneath everything, Ruby and Python included. I came to love its simplicity. Rust and Zig are well made, but for my work they always felt more complicated than they needed to be.

So I wrote the language I wanted: the simplicity of C, with the conveniences I kept reaching for in other languages. Today it builds itself and runs in production at ReactVision. If you build something with it, I would like to hear about it.

I made Eskiu with love and care, and I hope you enjoy it as much as I have enjoyed building it.

Eduardo DorantesCreator of Eskiu
