Write it like a script. Ship it like C.

A self-hosting systems language on LLVM, with explicit memory and direct C interop. One compiler for desktops, the web and phones.

Get started Try it in the browser
Install on macOS or Linux curl -fsSL https://eskiu-lang.org/install.sh | sh

Homebrew: brew install eskiu-lang/eskiu/eskiu · Windows and release archives

Why Eskiu

Fast

Native code through LLVM, with memory you manage and no garbage collector. A C library's structs and functions are called as they are, on every target.

C interop and ABIs →
Reliable

Sum types checked to the last case, nullable pointers checked before use, defer for cleanup, and bounds, overflow and null checks with --safe.

Ownership and resources →
Productive

Run a file like a script, with HTTP, JSON, files and processes in the standard library, packages in one command and an editor that knows your code.

What you can build

One language, from scripts to silicon.

WebAssembly

Compile for the browser

One flag builds a page, a module, or a library for an existing emscripten project. Exceptions, async code and C interop work there as they do natively, and ViroReact's AR tracking ships to the web this way.

$ eskiuc app.esk --target wasm32-unknown-emscripten -o app.js

Phones

Static libraries for iOS and shared libraries for Android, called from Swift, Kotlin or Objective-C.

GPU and machine learning

WebGPU compute and 3D, ONNX Runtime and TensorFlow Lite, each one package away.

Scripts and command-line tools

eskiuc run or a shebang, with argument parsing, HTTP, JSON and processes built in.

Network services

async HTTP/1.1 and HTTP/2 servers over one event loop on Linux, macOS and Windows.

Bare metal

Freestanding builds with inline assembly and volatile access. An ARM64 kernel boots in QEMU.

Inside a C or C++ codebase

A module with a C header drops into an existing engine, one file at a time. That is how it entered ViroReact.
The language

Familiar on the surface.

C's model of memory and data, with the checks and conveniences of a modern language, at no run-time cost.

Sum types, checked to the last case

An enum carries data per variant. Leave a case out of a match and it does not compile.

match parse_port("8080") {
    Port(p)         -> serve(p);
    InvalidRange(n) -> warn(n);
    NotANumber      -> fail();
}

Maths that reads like maths

Bounded generics are monomorphised; operator overloads resolve by operand type and compile to direct calls.

V3 operator +(V3 a, V3 b) { ... }
V3 operator *(V3 v, float s) { ... }

let mid: V3 = (a + b) * 0.5;

async, await and typed channels

One reactor on kqueue, epoll or WSAPoll: the same networking code runs on Linux, macOS and Windows.

async int sum_squares(Chan<int>* ch) {
    let a: int = await Chan_recv(ch);
    let b: int = await Chan_recv(ch);
    return a + b;
}

A standard library for scripts

Fetch over HTTPS, walk a directory, run a command, read JSON and CSV, with modules that ship with the compiler.

let r: Response;
fetch("https://api.github.com/repos/x/y", &r);
defer Response_free(&r);
println(JsonValue_as_cstr(json_get(
    Response_json(&r), "owner.login")));

The compiler is written in Eskiu too: the whole pipeline rebuilds itself to the same output through a three-stage bootstrap. How it bootstraps →

Get started

Three steps to a running program.

  1. 1

    Install

    curl -fsSL https://eskiu-lang.org/install.sh | sh

    Or brew install eskiu-lang/eskiu/eskiu, or a release archive for Windows.

  2. 2

    Write hello.esk

    import <io>;

println("Hello, Eskiu!");

    A file with statements at the top level runs as a script; larger programs have a main.

  3. 3

    Run it

    $ eskiuc run hello.esk
Hello, Eskiu!

    eskiuc hello.esk -o hello builds a native executable instead.
