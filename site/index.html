Your coding agent builds, sees and tests the app

One small set of operations drives the running app on the web, iOS, Android, macOS, Linux and Windows. The test owns the clock, so nothing moves between steps.

  • The same .uitest files on every platform
  • Compiled out of release builds

export · --emit-header

Inside an existing C or C++ codebase

export makes a function callable from C, C++ or Rust, and --emit-header writes its header. A module drops into an engine one file at a time, which is how Eskiu entered ViroReact.

  • Structs by value in each target's C ABI
  • Static and shared libraries for iOS and Android
  • Sum types, defer and checked nullable pointers at no run-time cost
C interop and ABIs →
export int checksum(*uint8 data, int n) {
    int sum = 0;
    for (i in 0..n) sum = sum * 31 + data[i];
    return sum;
}

$ eskiuc lib.esk --emit-header lib.h
$ eskiuc lib.esk -o liblib.a

A note from the developer

A note from the developer

I learned to program with Ruby, but the more I built, the more I found C underneath everything, Ruby and Python included. I came to love its simplicity. Rust and Zig are well made, but for my work they always felt more complicated than they needed to be.

So I wrote the language I wanted: the simplicity of C, with the conveniences I kept reaching for in other languages. Today it builds itself and runs in production at ReactVision. If you build something with it, I would like to hear about it.

I made Eskiu with love and care, and I hope you enjoy it as much as I have enjoyed building it.

Eduardo DorantesCreator of Eskiu
