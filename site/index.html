01

Sum types, checked to the last case

An enum carries data per variant. Leave a case out of a match and it does not compile.

match parse_port("8080") {
    Port(p)         -> printf("listening on :%d\n", p);serve(p);
    InvalidRange(n) -> printf("%d out of range\n", n);warn(n);
    NotANumber      -> printf("not a number\n");fail();
}
02

Vector maths that reads like maths

Bounded generics are monomorphised; operator overloads resolve by operand type and cost nothing at run time.

V3 operator +(V3 a, V3 b) { ... }
V3 operator *(V3 v, float s) { ... }

let mid: V3 = (a + b) * 0.5;  // direct calls
03

async, await and typed channels

One reactor on kqueue, epoll or WSAPoll, so the same networking code runs on Linux, macOS and Windows.

async int sum_squares(Chan<int>* ch) {
    let a: int = await Chan_recv(ch);
    let b: int = await Chan_recv(ch);
    return a + b;
}
04

The compiler is written in Eskiu

Self-hosting. The whole pipeline reproduces its own output through a 3-stage bootstrap fixpoint.

How it bootstraps → 
selfhost/
  lexer → preprocessor → parser
  → sema → codegen → LLVM

stage 1 → 2 → 3  ✓ fixpoint
05

A standard library for scripts

Fetch a URL over HTTPS, walk a directory, run a command, parse arguments or read JSON and CSV with modules that ship with the compiler.

Scripting with Eskiu → 
let r: Response;
fetch("https://api.github.com/repos/llvm/llvm-project", &r);
defer Response_free(&r);

*JsonValue repo = Response_json(&r);
println(JsonValue_as_cstr(json_get(repo, "owner.login")));
