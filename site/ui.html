Native apps, written in Eskiu

One codebase for iOS, Android, the web and the desktop. Each platform draws its own controls, so the app looks and behaves the way people expect there.

Native, not a lookalike

Text, buttons, fields, lists and alerts are the platform's own controls, laid out by Yoga, the engine React Native uses.

  • VoiceOver, TalkBack and the system's text size
  • Passwords, keyboards and autofill in forms
  • Dark mode, safe areas, haptics, sharing
  • Camera, location and notifications as packages

Quick to build

Save a file and the running app changes in a third of a second, on the same screen, with its state kept.

  • A themed kit: forms, pickers, menus, toasts
  • Navigation that is screens on phones and URLs on the web
  • Errors that name the element and its source line
  • Native code in Swift, Kotlin or JavaScript when you need it

Made for agents and tests

A coding agent can build a screen, look at it and tap through it without a person in the loop.

  • ui agent: the tree, screenshots, taps and typing
  • ui test: one .uitest file for every platform
  • A clock the test controls, so tests never sleep
  • Nothing of it in a release build

A screen is an Eskiu function

Components are ordinary functions that keep their state in signals. When a signal changes, only the blocks that read it run again. The app compiles to machine code on phones and desktops and to WebAssembly on the web, with no JavaScript bridge in between.

import <ui>;

void Counter() {
    Column(Style{padding: 24, gap: 12}) {
        *Signal<int> count = use_signal<int>(0);
        TextWith(Style{font_size: 28, font_weight: 700},
            textf("Pressed %d times", count.get()));
        Button("Press me") {
            count.set(count.get() + 1);
        }
    }
}

Components that come ready

<ui/kit> has cards, buttons, fields, checkboxes, tabs, bars, a calendar, menus, popovers and toasts, themed in light and dark, in English or Spanish, with their roles and states for screen readers.

From an empty folder to the stores

The ui tool makes the project, runs it while you work and builds what you ship.

  1. ui new myappA project with an app, a test and an AGENTS.md for coding agents.
  2. ui serve iosRuns the app and rebuilds it on every save. Also android, web, macos, linux and windows.
  3. ui releaseSigned builds for the App Store and Google Play, the desktop and the web. ui open ios works from Xcode.

Install the tool:

git clone https://github.com/eskiu-packages/ui
eskiuc ui/tools/ui/main.esk -o ~/.eskiu/bin/ui
