For coding agents

Eskiu for agents

An agent with a computer of its own (a Linux machine, a container) can install Eskiu, write programs and apps, run them, look at them and test them with the commands on this page. Every answer has a form meant for a program to read.

Install

The compiler and the ui tool, under ~/.eskiu when /usr/local is not writable:

curl -fsSL https://eskiu-lang.org/install.sh | sh -s -- --with-ui
export PATH="$HOME/.eskiu/bin:$PATH"
eskiuc doctor

On Windows, $env:ESKIU_WITH_UI = 1; irm https://eskiu-lang.org/install.ps1 | iex. Or start from the container image, which already holds eskiuc, ui, emscripten and Chrome: 

docker run --rm -it ghcr.io/eskiu-lang/agent

eskiuc doctor lists what the machine has for each kind of build and what is missing. A native build needs a C compiler (clang or gcc); a web app needs emscripten (emcc) and, to drive it, Chrome or Chromium.

Write and run code

eskiuc run hello.esk                       # compile and run a file
eskiuc new tool && cd tool && eskiuc run     # a package
eskiuc test                                # each tests/*.esk, pass = exit 0
eskiuc main.esk -o app --diagnostics=json  # errors as JSON lines on stderr

With --diagnostics=json each error or warning is one JSON object: its severity, a stable id, the message, the file and range, hints and notes. The ids are listed in diagnostic-ids.txt.

Build an app and look at it

ui agent drives the running app: it builds it, starts it in a headless Chrome (on the web) or in a window, and answers each operation. --json gives one object per operation. 

ui new myapp && cd myapp
ui agent web --json tree
ui agent web --json "tap add" "type title Milk" "clock settle" state
ui agent web "screenshot shot.png"
ui agent web --stop

The operations are tree, layout, screenshot FILE, tap ID, type ID TEXT, scroll ID DY, back, clock +MS, clock settle, state, logs and perf. Elements are named by Style.test_id. Time moves only with clock, so nothing changes between two operations. On a Linux machine that runs as root, Chrome needs UI_CHROME_ARGS=--no-sandbox.

The same operations drive the app on macOS, Linux and Windows windows, the iOS simulator and Android, when the machine has them: ui agent ios ..., ui agent android ....

Test it

# tests/ui/counter.uitest
expect count text "Count: 0"
tap Increment
expect count text "Count: 1"
expect screenshot counted 0.5%

ui test web --json

A .uitest file runs unchanged on every platform. Every ui new app starts with one, and with an AGENTS.md that tells an agent how to work on it.

Without a computer of its own

An agent that only talks (Claude, ChatGPT and other MCP clients) reaches Eskiu through its MCP server, a remote URL with no key: 

https://eskiu-mcp-9450.orvex.cloud/mcp

It searches the compiler, the standard library and the docs, and runs code on a worker: eskiu_run compiles and runs a file, eskiu_ui_render builds a ui app for the web, applies ui agent operations and returns a screenshot, and eskiu_ui_test runs a .uitest file against it.
